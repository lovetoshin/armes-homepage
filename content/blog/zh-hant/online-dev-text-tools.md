## 文字類工具

### 字數統計
最常用於報告、個人履歷或文章有字數限制時。使用能**分別統計含空格與不含空格**字數的工具，結果更精確。

> 注意：不同提交平台的標準不同，「含空格1000字」還是「不含空格」要仔細確認。同一篇文章，兩種算法可能相差幾十個字。

### 大小寫與全形/半形轉換
一次性將英文轉為全大寫或全小寫，或將資料中混入的全形字元（`ＡＢＣ`）整理為一般字元（`ABC`）。

```text
輸入      :  armes tools
大寫      :  ARMES TOOLS
首字母大寫 :  Armes Tools
```

### 刪除重複行並排序
從名單或列表中刪除重複項，並依字母順序排序。特別適合整理電子郵件地址和關鍵字列表。

```text
[處理前]              [刪除重複並排序後]
kim@a.com             choi@c.com
lee@b.com    →        kim@a.com
kim@a.com             lee@b.com
choi@c.com
```

1000封郵件裡手動找重複項幾乎不可能，但用工具1秒搞定。

## 開發者與專業工具

### JSON 格式化
將壓縮在一行的資料展開，使其清楚易讀。讀取 API 回應或定位錯誤時不可或缺。

```text
[處理前] {"id":1,"tags":["a","b"]}
[處理後] {
           "id": 1,
           "tags": ["a", "b"]
         }
```

### 編碼／解碼
- **Base64：** 將資料轉為文字進行傳輸（`ARMES` → `QVJNRVM=`）。
- **URL 編碼：** 將網址中的特殊字元和非 ASCII 文字安全轉換（`空格` → `%20`）。

### 色彩代碼與時間戳記轉換
- **色彩代碼轉換：** 設計時用 HEX（`#1D62F0`），寫程式時用 RGB（`rgb(29,98,240)`），互相轉換十分方便。
- **時間戳記轉換：** 將日誌或資料庫中以數字儲存的時間（`1750000000`）轉為人類可讀的日期。

## 使用工具時的原則（安全）

方便歸方便，不能隨便把資料貼到任何工具裡。文字和開發資料中很容易混入**公司機密、客戶名單、API 金鑰和個人資訊**。

- **確認資料是否在本機處理：** 資料不上傳至伺服器、在瀏覽器內處理，安全性更高。
- **敏感值用測試資料替代：** 正式環境的 API 金鑰和存取權杖，絕對不要貼到任何線上工具中。請換成假的測試資料來操作。
- **公用電腦使用後清理：** 刪除輸入內容，清空下載資料夾。

## 常見問題（FAQ）

**Q. 線上工具真的不需要安裝嗎？**
大多數工具在瀏覽器裡直接使用。字數統計、JSON 格式化、編碼等，打開頁面輸入即可，無需安裝任何軟體。

**Q. 應該先學哪些工具？**
最常用的是：字數統計、刪除重複行、JSON 格式化、URL 編碼。只要掌握這四個，效果立竿見影。

**Q. 可以把正式環境 API 金鑰貼到線上工具裡嗎？**
很危險。如果工具會將輸入內容上傳至伺服器，金鑰就可能外洩。請務必用測試用的假資料替代。

**Q. 為什麼需要 JSON 格式化工具？**
API 回應通常是一行壓縮的資料，很難閱讀。格式化之後結構一目了然，還能幫你定位語法錯誤，工作效率大幅提升。

**Q. Base64 和 URL 編碼有什麼區別？**
Base64 是把資料包裝成文字，URL 編碼是把不能出現在網址中的字元轉換為 `%` 格式。兩者用途不同。

**Q. 能一次性清除郵件名單中的重複項嗎？**
可以。把列表貼到刪除重複行工具裡，重複的行會自動刪除，再排個序就更整齊了。

**Q. 字數統計是否包含空格？**
工具通常會同時顯示含空格和不含空格兩種數字。請根據提交要求選擇合適的數字。

**Q. 每次找工具太麻煩了。**
把常用工具加入瀏覽器書籤，或者使用將多個工具集合在一處的工具集，是最方便的解決方式。
