一進好市多(Costco)就有一種「在這裡買什麼都划算」的感覺，購物車很快就裝滿了。但結帳後看到收據時，「咦，沒想到花了這麼多」的體驗，相信很多人都有過。事實是這樣的：**Costco並不是所有商品都便宜。** 由於是大容量，總價看起來很大，但按單價來算，有些商品與一般超市相比價格差不多，甚至更貴。

## 「便宜」的標準是單價

Costco最大的陷阱就是大容量。「一整罐才一萬韓元」看起來很便宜，但同樣的量在一般超市分開買可能更便宜。所以比較時一定要以**每100g·每個·每公升的單價**來衡量。賣場價格標籤上通常會小字標注單位價格，要養成看那個數字的習慣。

## CP值好的 vs 需要注意的品類

| CP值好的 | 需要注意的 |
| --- | --- |
| 衛生紙·洗潔劑·衛生用品（都能用完） | 大容量生鮮食品（變質則虧本） |
| 堅果·罐頭·咖啡（保存期限長） | 服裝·家電·季節性貨架（容易衝動消費） |
| 密封袋·烘焙紙（消耗品） | 偶爾用的大容量香料（最終丟掉） |
| 經常吃的冷凍食品 | 單人家庭的超大容量 |

### CP值好的品類
- **長期使用的生活必需品：** 衛生紙·洗潔劑·衛生用品。反正都會用完，單價優勢可以完整保留。
- **常溫保存食品：** 堅果·罐頭·咖啡等保存期限較長的食品。
- **經常使用的消耗品：** 密封袋·烘焙紙等用完就需要補充的東西。

### 需要注意的品類
- **大容量生鮮食品：** 在用完之前就壞掉，即使單價便宜也是虧本。要考慮家庭人數。
- **衝動消費區：** 服裝·家電·季節性商品容易因為「反正有」而拿進購物車，而不是真的需要。
- **少量就夠用的東西：** 偶爾才用的香料買大容量，最終往往會丟掉。

## 購買前的4項核查清單

| 問題 | 通過標準 |
| --- | --- |
| 是否按單價比較了 | 單位價格，而非總價 |
| 是否能用完這個量 | 保存期限×家庭人數 |
| 是否有足夠的儲存空間 | 大容量佔地方 |
| 是真的需要嗎 | 是否只是「順手拿」的東西 |

通過這四項，那件商品就值得買。

## 再加上折扣價格訊號

在CP值標準之上再加上折扣訊號，購物會更聰明。價格標籤上的.97和星號(*)分別是什麼意思，請參考[Costco價格標籤數字和星號的隱藏含義](/blog/costco-price-tag-secrets)；本週折扣確認方法請參考[如何查看Costco本週折扣商品](/blog/costco-weekly-deals)；考慮會員費的消費方式請參考[Costco會員費如何物有所值](/blog/costco-membership-worth)；與網路價格的比較請參考[如何找到網路最低價](/blog/online-lowest-price)。

## 注意事項

- **警惕「無條件划算」的神話。** 不按單價比較，貴的東西也會感覺便宜。
- **保存期限=真實成本。** 用不完丟掉，無論單價多低都是虧損。
- **不要被試吃左右。** 嚐了一口不代表一定要買。

## 結論

Costco高CP值的關鍵在於**按單價比較，只買能用完的量**。不要因為是大容量就認為便宜，要同時考慮單位價格和實際用量。只要堅守這個標準，Costco就一定會成為一個真正實惠的購物場所。

## 常見問題（FAQ）

**Q. Costco不是所有東西都便宜嗎？**
不是的。因為是大容量，總價看起來大，單價看起來低，但按單價比較，有些商品與一般超市差不多甚至更貴。

**Q. 單價怎麼比較？**
換算成每100g·每個·每公升的價格來比較。Costco的價格標籤上很多情況下會小字標注單位價格。

**Q. 單人家庭去Costco也划算嗎？**
生活必需品和常溫食品還好，但大容量生鮮食品容易浪費。先考慮量和儲存空間。

**Q. 哪些商品CP值特別好？**
衛生紙·洗潔劑等生活必需品，堅果·咖啡等常溫食品，以及密封袋等消耗品的單價競爭力通常較高。

**Q. 生鮮食品一定不能買嗎？**
如果能用完就沒問題。但不考慮家庭人數和保存期限就購買，浪費的成本往往更大。

**Q. 有減少衝動消費的方法嗎？**
定好清單再去，在服裝·家電·季節性貨架前再問一次「真的需要嗎？」。

**Q. 價格標籤訊號也要一起看嗎？**
是的。將.97（折扣）·星號（停產）與單價比較結合起來，購物會更聰明。

**Q. Costco比網路更便宜嗎？**
因商品而異。養成按單價與網路最低價比較後再決定的習慣更安全。
