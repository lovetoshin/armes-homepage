在好市多(Costco)常客之間流傳著一句話：「只看價格標籤就能知道是不是打折商品。」一開始聽起來像是傳說，但實際上Costco價格標籤的**末位數字和星號(\*)確實隱藏著一定的規律**。知道這套規則的人和不知道的人，在同一家賣場裡的購物體驗會截然不同。前者能第一眼識別出「現在不買就沒有的折扣商品」，後者卻只是從旁邊走過。

這些訊號也很容易記。核心只有兩點：**末位數字和星號**。這篇文章將整理各自的含義、組合解讀方法，以及光看價格標籤還不夠的部分。

## 末位數字的訊號

Costco價格標籤上最有名的規則就是**末位數字**。

- **以.99結尾：** 通常是正常價格。可以理解為基本銷售價格。
- **以.97結尾：** 很多情況下是門市降價處理的**折扣（降價）商品**。是為了快速清庫存而降價的。
- **以.00或.88等結尾：** 可能是門市特別處理的價格，也被視為額外折扣訊號。

也就是說，**發現.97就值得多看一眼**。

## 星號(*)的含義

價格標籤**右上角有小星號(\*)**的話，是重要的訊號。通常意味著「**這件商品可能不會再補貨**」。會標注在停產或季節性結束、不再進貨的商品上。如果平時常買的商品突然出現了星號，說明下次來可能就看不到了，如果需要，那時候就要順手拿。

## 組合看價格標籤訊號

| 組合 | 解讀 |
| --- | --- |
| **.97 + 星號** | 折扣 + 即將停產 → 「現在不買就買不到了」 |
| **只有.97** | 正在打折 → 常用的話可以囤貨 |
| **.99 + 星號** | 正常價但即將停產 → 需要的話提前備貨 |
| **只有.99** | 平時價格 → 不急 |

只要熟悉這些組合，在賣場裡幾秒鐘就能做出判斷。

## 光看價格標籤還不夠的地方

價格標籤只顯示「當下」的資訊。要知道這個價格是否比平時真的便宜，需要看**過去的價格走勢**。同樣是.97，原來很貴現在降了，和原來就便宜的情況，價值是完全不同的。所以追蹤關注商品的歷史價格非常重要 — ARMES的**CocoPing**也正是朝著這個方向打造的。本週折扣確認方法請參考[如何查看Costco本週折扣商品](/blog/costco-weekly-deals)，判斷真正高CP值商品的方法請參考[在Costco挑選高CP值商品的標準](/blog/costco-best-value-items)。

## 注意事項

- **訊號是規律，不是絕對規則。** 因門市和時間不同可能會有例外，請結合標籤一起確認。
- **不要被星號壓力左右。** 不要因為「快消失了」就衝動購買不需要的東西。
- **.97也要用單價驗證。** 即使是折扣，如果單價比附近超市還貴，那也不是真的划算。

## 結論

Costco價格標籤不只是簡單的數字，而是**告知折扣和停產的訊號板**。**.97是折扣，星號是即將停產** — 只記住這兩點，在賣場裡就能聰明很多。再加上價格走勢追蹤，就能只在真正便宜的時候才買。更聰明地使用會員資格的方法，請繼續閱讀[Costco會員費值回本錢的消費模式](/blog/costco-membership-worth)。

## 常見問題（FAQ）

**Q. 價格以.97結尾就一定是折扣嗎？**
大體上意味著降價（折扣）商品。但因門市和時間不同可能會有例外，請結合標籤一起確認。

**Q. .99是什麼意思？**
通常是正常價格。可以理解為基本銷售價格，不需要急著買。

**Q. 星號(*)標注在哪裡？**
標注在價格標籤右上角的小位置。是不再補貨、可能停產的訊號。

**Q. 有星號的商品一定要現在買嗎？**
如果是需要的東西，趁看到的時候備貨更安全。但不需要因為「快消失了」就買不必要的東西。

**Q. .97+星號是什麼意思？**
正在打折且即將停產，是「現在不買就買不到了」的最強烈購買訊號。

**Q. .00或.88結尾是什麼意思？**
可能是門市特別處理的價格，也被視為額外折扣訊號。結合其他標注一起確認。

**Q. 只看折扣標識就可以買嗎？**
價格標籤只顯示「當下」。要確認是否比平時真的便宜，還需要結合歷史價格走勢和單價一起看。

**Q. 這些訊號在所有Costco門市都一樣嗎？**
這是一般性規律，不是絕對規則。因門市、國家和時間不同可能會有差異。
