## 自助加油站為什麼便宜

自助加油站比有服務人員的加油站價格更低，是有明確原因的。

| 原因 | 說明 |
| --- | --- |
| 節省人力成本 | 沒有加油員，營運成本↓ → 反映在售價上 |
| 薄利多銷模式 | 透過提高周轉量來壓低單價 |
| 自己動手加油 | 稍微費點事 → 每公升節省若干元 |

代價只是自己動手加油，而每次加油實實在在能節省一些錢。不過，自助油站之間也因地點和品牌不同而有價差，所以找到附近真正最便宜的那家依然重要——[如何找到附近最便宜的加油站](/blog/cheapest-gas-station)。

## 加油折扣卡怎麼選

折扣卡種類繁多，容易讓人眼花繚亂。選之前確認這四點：

| 確認項目 | 核心問題 |
| --- | --- |
| 折扣方式 | 按公升數折扣？還是帳單折扣？ |
| 上月消費門檻 | 我的日常消費能達到門檻嗎？ |
| 折扣上限 | 每月最多能省多少？ |
| 年費 | 全年折扣總額 − 年費 > 0 嗎？ |

### 1. 按公升折扣 vs. 帳單折扣
「每公升優惠 X 元」這樣按加油量比例折扣的方式，與按消費總額回饋一定比例的帳單折扣，是兩種不同模式。**如果加油量大，按公升折扣通常更划算。**

### 2. 上月消費門檻
大多數折扣卡要求「上月消費滿多少才享受優惠」。先確認自己的日常刷卡消費能否達到這個門檻。

### 3. 折扣上限
通常有「每月最多優惠多少元」這樣的上限。加油量大的話，選上限更高的卡更合適。

### 4. 年費
如果年費高於全年折扣總額，就是在虧本。必須算清楚：**全年折扣總額 − 年費**是否為正數。

## 疊加更多優惠

- **電信和會員回饋：** 部分加油站有電信業者或會員合作，可額外累積點數。
- **點數折抵油費：** 累積的點數可以像現金一樣用於加油。
- **App 優惠券：** 部分加油相關 App 會不定期發放一次性折扣券，值得留意。

## 注意事項

- **別只為加油折扣辦多張卡。** 多張卡的年費和消費門檻管理起來反而是負擔。選一張符合自己習慣的就夠了。
- **定期確認優惠條件有無變動。** 信用卡優惠可能會調整，建議定期核對。
- **自助加油的油品質量同樣有保障。** 油量和油品質量都受監管，自助和有人服務的油質沒有區別，只需按價格選擇即可。

## 常見問題解答（FAQ）

**Q. 自助加油站為什麼更便宜？**
沒有加油員，節省了人力成本，價格也因此降低。薄利多銷的營運模式也是原因之一。

**Q. 自助加油的油品質量會差一點嗎？**
不會。油量和質量都受監管，自助和有人服務的油質完全相同，可以放心按價格選擇。

**Q. 按公升折扣和帳單折扣哪個更划算？**
加油量大選按公升折扣更合算；非加油消費多的話，帳單折扣卡可能更適合。按自己的消費習慣計算一下。

**Q. 上月消費門檻一定要達到嗎？**
大多數折扣都有這個條件。達不到門檻就沒有折扣，申請前務必確認自己的日常消費能否滿足。

**Q. 年費值得嗎？**
算出全年折扣總額減去年費的結果，如果是負數，這張卡對你來說就是虧本的。

**Q. 加油折扣卡辦幾張合適？**
一張符合自己加油習慣的就夠了。多辦幾張反而要分別管理年費和消費門檻，徒增麻煩。

**Q. 點數可以用來加油嗎？**
很多情況下可以。電信點數、會員點數和信用卡點數通常都能在加油時折抵，建議充分利用。

**Q. 綜合來看，最省錢的加油組合是什麼？**
在附近最便宜的自助加油站，用符合自己消費習慣的折扣卡加油，再疊上可用點數——這個組合最划算。
