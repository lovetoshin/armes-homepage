## 文本类工具

### 字数统计
最常用于报告、个人简历或帖子有字数限制时。使用能**分别统计含空格与不含空格**数量的工具，结果更精准。

> 注意：不同提交平台的标准不同，"含空格1000字"还是"不含空格"要仔细确认。同一篇文章，两种算法可能相差几十个字。

### 大小写与全角/半角转换
一次性将英文转为全大写或全小写，或将数据中混入的全角字符（`ＡＢＣ`）整理为普通字符（`ABC`）。

```text
输入  :  armes tools
大写  :  ARMES TOOLS
首字母大写 :  Armes Tools
```

### 删除重复行并排序
从名单或列表中删除重复项，并按字母顺序排序。特别适合整理邮件地址和关键词列表。

```text
[处理前]              [删除重复并排序后]
kim@a.com             choi@c.com
lee@b.com    →        kim@a.com
kim@a.com             lee@b.com
choi@c.com
```

1000封邮件里手动找重复项几乎不可能，但用工具1秒搞定。

## 开发者与专业工具

### JSON 格式化
将压缩在一行的数据展开，使其清晰易读。读取 API 响应或定位错误时必不可少。

```text
[处理前] {"id":1,"tags":["a","b"]}
[处理后] {
           "id": 1,
           "tags": ["a", "b"]
         }
```

### 编码/解码
- **Base64：** 将数据转为文本进行传输（`ARMES` → `QVJNRVM=`）。
- **URL 编码：** 将地址中的特殊字符和非 ASCII 文本安全转换（`空格` → `%20`）。

### 颜色代码与时间戳转换
- **颜色代码转换：** 设计时用 HEX（`#1D62F0`），写代码时用 RGB（`rgb(29,98,240)`），互相转换十分方便。
- **时间戳转换：** 将日志或数据库中以数字存储的时间（`1750000000`）转为人类可读的日期。

## 使用工具时的原则（安全）

方便归方便，不能随便把数据粘贴到任何工具里。文本和开发数据中很容易混入**公司机密、客户名单、API 密钥和个人信息**。

- **确认数据是否在本地处理：** 数据不上传到服务器、在浏览器内处理，安全性更高。
- **敏感值用测试数据替代：** 生产环境的 API 密钥和令牌，绝对不要粘贴到任何在线工具中。请换成假的测试数据来操作。
- **公用电脑使用后清理：** 删除输入内容，清空下载文件夹。

## 常见问题（FAQ）

**Q. 在线工具真的不需要安装吗？**
大多数工具在浏览器里直接使用。字数统计、JSON 格式化、编码等，打开页面输入即可，无需安装任何软件。

**Q. 应该先学哪些工具？**
最常用的是：字数统计、删除重复行、JSON 格式化、URL 编码。只要掌握这四个，效果立竿见影。

**Q. 可以把生产环境 API 密钥粘贴到在线工具里吗？**
很危险。如果工具会将输入内容上传到服务器，密钥就可能泄露。请务必用测试用的假数据代替。

**Q. 为什么需要 JSON 格式化工具？**
API 响应通常是一行压缩的数据，很难阅读。格式化之后结构一目了然，还能帮你定位语法错误，工作效率大幅提升。

**Q. Base64 和 URL 编码有什么区别？**
Base64 是把数据包装成文本，URL 编码是把不能出现在地址栏中的字符转换为 `%` 格式。两者用途不同。

**Q. 能一次性清除邮件名单中的重复项吗？**
可以。把列表粘贴到删除重复行工具里，重复的行会自动删除，再排个序就更整洁了。

**Q. 字数统计是否包含空格？**
工具通常会同时显示含空格和不含空格两种数字。请根据提交要求选择合适的数字。

**Q. 每次找工具太麻烦了。**
把常用工具加入浏览器书签，或者使用将多个工具集合在一处的工具集，是最方便的解决方式。
