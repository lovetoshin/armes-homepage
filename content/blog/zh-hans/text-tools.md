## 字数与词数统计

最常用于简历、报告、帖子有字数限制时。使用能**分别统计含/不含空格**的工具，结果最为准确。

> 注意：不同提交平台对字数的计算标准不同。请务必确认是"含空格 1000 字以内"还是"不含空格"，同一篇文章含/不含空格可能相差几十个字。

## 大小写与全角/半角转换

```text
输入      :  armes tools
大写      :  ARMES TOOLS
小写      :  armes tools
首字母大写 :  Armes Tools
```

- **大小写转换：** 将英文全部转为大写/小写，或仅将首字母大写。
- **全角 → 半角：** 将数据中混入的全角字符（`ＡＢＣ１２３`）整理为普通字符（`ABC123`）。在 Excel 和数据处理中经常需要。

## 删除重复行并排序（实战示例）

对名单或列表**一键删除重复行**，并按字母顺序排序。特别适合整理邮件地址和关键词列表。

```text
[处理前]           [去重 + 排序后]
kim@a.com          choi@c.com
lee@b.com    →     kim@a.com
kim@a.com          lee@b.com
choi@c.com
```

手动在 1000 条邮件名单中找重复几乎不可能，而工具只需 1 秒。

## 查找替换 / 空格整理

## ⚠️ 安全使用须知

文本中往往包含**公司机密、客户名单和个人信息**。

- 敏感内容请只使用**数据在浏览器本地处理、不上传至服务器**的工具。
- 在公用电脑上操作完成后，请清除输入内容。
- 客户邮箱和电话号码名单尤其需要谨慎处理。

## 常见问题（FAQ）

**Q. 字数统计包含空格吗？**
工具通常会同时显示含/不含空格两种统计结果。请确认提交平台的标准（含/不含）后使用对应数字。

**Q. 中文字数也能准确统计吗？**
可以。工具会分别统计中文字符、英文字母、数字和空格。但各机构标准不同，请务必确认提交要求。

**Q. 如何一次性删除邮件名单中的重复项？**
将列表粘贴到去重工具中，相同行会被自动删除。再排序一下会更整齐。

**Q. 什么是全角字符？为什么需要整理？**
像 `ＡＢＣ` 这样宽度较大的字符。混入数据后会导致搜索和统计出错，应统一为普通（半角）字符。

**Q. 和记事本的查找替换有什么区别？**
这类工具通常支持同时替换多个词、整理换行和空格，以及正则表达式等高级功能，速度更快。

**Q. 复制来的文章换行乱了，能整理吗？**
可以。有专门的功能一键清除多余换行和重复空格，非常适合粘贴后的文本整理。

**Q. 把客户名单放到在线文本工具里安全吗？**
如果工具会将输入内容上传至服务器则存在风险。含个人信息的名单请只使用在浏览器本地处理的工具。

**Q. 每次都要搜索常用工具，很麻烦怎么办？**
将常用工具添加到书签，或使用将多个工具集中在一处的工具合集，会方便很多。
