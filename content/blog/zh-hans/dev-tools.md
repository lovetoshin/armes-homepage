## 数据整理与转换

### JSON 格式化
将压缩成一行的 JSON 展开并加入缩进，让结构一目了然，是开发和调试的必备工具。

```text
[处理前] {"id":1,"tags":["a","b"]}
[处理后] {
           "id": 1,
           "tags": ["a", "b"]
         }
```

详细介绍请参考[JSON 格式化（整理）方法](/blog/json-format)。

### 编码 / 解码
- **Base64：** 将数据转换为文本字符串便于传输（`ARMES` → `QVJNRVM=`）。原理说明请参考[轻松理解 Base64 编码与解码](/blog/base64-guide)。
- **URL 编码：** 将 URL 中的特殊字符和中文等安全处理（`空格` → `%20`）。详见[什么是 URL 编码？](/blog/url-encoder)。

## ⚠️ 安全使用指南（开发者尤其重要）

开发数据中往往混有 **API 密钥、Token、数据库连接信息、用户数据**等高度敏感的内容。

| 检查项 | 原因 |
| --- | --- |
| 是否在浏览器本地处理 | 输入内容不上传服务器，泄露风险大幅降低 |
| 确认公司安全规定 | 部分公司禁止使用外部在线工具 |
| 密钥和 Token 不要粘贴进工具 | 一旦意外上传，可能引发安全事故 |

> 特别提醒：**将生产环境 API 密钥或 Token 随意粘贴到在线工具中**，存在严重的安全风险。敏感数据请使用浏览器本地处理的工具，或用测试用的假数据替代。

## 常见问题（FAQ）

**Q. 开发者在线工具真的不需要安装吗？**
大部分直接在浏览器中运行。JSON 格式化、编码、颜色转换等，打开页面、粘贴内容即可使用。

**Q. 可以把生产环境 API 密钥粘贴到在线工具里吗？**
有风险。如果工具会将输入内容上传服务器，密钥可能泄露。请使用浏览器本地处理的工具，或用测试用假数据代替。

**Q. 为什么需要 JSON 格式化工具？**
API 响应往往是压缩成一行的 JSON，几乎无法直接阅读。格式化后结构清晰可见，语法错误的位置也能一目了然，调试效率大幅提升。

**Q. Base64 和 URL 编码有什么区别？**
Base64 是将数据打包成文本字符串，URL 编码是将 URL 中不允许的字符转换为 `%` 形式。用途不同。

**Q. 为什么要转换颜色代码？**
设计稿常用 HEX（`#...`），代码里有时用 RGB 更方便，互相转换时用转换工具即时换算。

**Q. 时间戳转换在什么时候用？**
当日志或数据库中的时间以纯数字（Unix 时间戳）存储时，转换成人类可读的日期来查看。

**Q. 哈希生成有什么用？**
用于确认文件或文本是否被篡改（完整性校验）。注意：哈希不等于加密。

**Q. 每次分别去找不同工具太麻烦了。**
使用将常用工具集中到一处的工具合集就能解决。收藏一个书签，效率大幅提升。
