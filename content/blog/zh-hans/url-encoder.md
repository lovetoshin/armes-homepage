你有没有复制过一个链接，发现地址里**混满了 `%20`、`%EC%95%88` 这样的奇怪字符**？或者把含有中文的网址通过聊天软件发给别人，结果**变成乱码打不开**？这些情况都与 **URL 编码**有关。

URL 编码其实并不复杂，它只是**把网址中无法使用的字符转换成安全格式的一种约定**。本文将详细介绍 URL 编码是什么、为什么会出现 `%` 字符、实际转换示例、如何解开乱码网址，以及重复编码这种常见错误。

## 什么是 URL 编码

网址（URL）对**可使用的字符有明确规定**。只有英文字母、数字和少数符号（`-`、`_`、`.`、`~`）可以安全使用，**空格、中文字符和特殊符号不能直接出现在网址中**。URL 编码（百分号编码）就是将这些字符转换为安全格式的方法。

原理很简单：将不可用的字符转换为 **`%` + 十六进制代码**。这就是为什么编码后的网址里充满了 `%` 符号。

## 编码前后 — 实际示例

```text
空格           →  %20
中文"安"       →  %E5%AE%89   （UTF-8 共 3 字节）
&              →  %26
?              →  %3F
搜索词"美食"   →  %E7%BE%8E%E9%A3%9F
```

例如，`armes.co.kr/搜索?q=美食 推荐` 编码后变为：

```text
armes.co.kr/%E6%90%9C%E7%B4%A2?q=%E7%BE%8E%E9%A3%9F%20%E6%8E%A8%E8%8D%90
```

看起来很奇怪，但这正是为了确保网址在任何环境下都能正确传输的约定。

## 编码与解码

| 类型 | 方向 | 使用时机 |
| --- | --- | --- |
| 编码（Encode） | 人类可读地址 → `%` 格式 | 创建或分享网址时 |
| 解码（Decode） | `%` 格式 → 原始地址 | 需要读懂满是 `%` 的网址时 |

## 什么情况下需要用 — 实际使用场景

| 场景 | 原因 |
| --- | --- |
| 分享链接 | 将含中文或空格的网址通过消息/邮件无损传输 |
| 搜索/参数处理 | 将搜索词嵌入网址（`?q=`）时 |
| API 请求 | 在请求地址中包含中文或特殊字符时 |
| 广告/流量分析 | 在 `utm_` 参数中嵌入推广活动名称时 |

## ⚠️ 最常见的错误 — 重复编码

对**已经编码过的网址再次编码**，`%` 会变成 `%25`，导致网址更加混乱。这就是"明明编码了，结果更乱"的原因。

```text
原始          :  安
编码一次      :  %E5%AE%89     （正常）
编码两次      :  %25E5%2598%25AE%2589  （乱码 — % 变成了 %25）
```

> 规则：**只编码一次。** 如果网址中已经有 `%XX`，就不要再编码了。如果搞不清楚，先解码还原原始内容，再重新编码一次。

## 补充知识

- **编码标准是 UTF-8：** 一个中文字符通常会变成三组 `%XX`。解码时也要用同样的标准，否则会出现乱码。
- **`+` 和 `%20`：** 空格通常用 `%20` 表示，但在某些表单提交中会用 `+` 来表示空格。两者都代表空格。
- **浏览器自动处理：** 现代浏览器会自动编码地址栏中的中文字符，但在代码中构造网址或对外传递参数时，手动编码更安全。

## 总结

URL 编码是**将网址中不可用的字符（空格、中文、特殊字符）转换为 `%` + 代码格式**的约定。遇到乱码网址就解码还原，需要分享的网址就编码后再发。**只要避免重复编码**，就不会有什么难度。

## 常见问题（FAQ）

**Q. 网址里的 `%20` 是什么意思？**
是空格的 URL 编码形式。因为空格不能直接出现在网址中，所以用 `%20` 来表示。

**Q. 中文字符为什么会变成 `%EC%95%88` 这样很长的形式？**
一个中文字符在 UTF-8 编码中通常占 3 个字节，每个字节会被编码为 `%XX`，因此会有三组。

**Q. 我编码了网址，反而更乱了。**
这是因为对已经编码过的网址又编码了一次。`%` 变成了 `%25` 导致更加混乱。请先解码还原为原始内容，再重新编码一次。

**Q. 什么时候用解码？**
当你想搞清楚一个满是 `%` 的网址实际是什么内容时使用。它是编码的反向操作，将网址还原为人类可读的形式。

**Q. `+` 和 `%20` 是一样的吗？**
两者都代表空格，但使用场景不同。在 URL 路径中用 `%20`，在某些表单提交中用 `+` 来表示空格。

**Q. 哪些字符需要编码？**
空格、中文字符、`&`、`?`、`#`、`/` 等特殊字符都需要编码。英文字母、数字和少数符号（`-_.~`）可以保持不变。

**Q. 浏览器会自动处理，还需要手动编码吗？**
在地址栏中浏览器会自动处理，但在代码中构造网址或向外部传递参数时，手动编码更安全。

**Q. 在线编码工具中粘贴敏感内容安全吗？**
如果工具会将输入上传至服务器，就需要注意。含有令牌或个人信息的网址，请只使用在浏览器本地处理的工具。
