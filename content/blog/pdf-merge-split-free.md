여러 장의 PDF를 하나로 합쳐 제출해야 할 때, 반대로 긴 PDF에서 필요한 몇 페이지만 떼어내야 할 때가 있습니다. 계약서·영수증·스캔본을 한 파일로 묶거나, 100쪽짜리 자료에서 3~7쪽만 보내야 하는 상황이죠. 이런 일은 생각보다 자주 생기는데, 그때마다 유료 PDF 프로그램(보통 월 결제)을 깔기는 부담스럽습니다. 실무에서 보면, 서류 제출 마감을 앞두고 파일이 여러 장으로 쪼개져 있어 "하나로 합쳐 오라"는 요청에 발을 동동 구르는 경우가 잦은데, 이럴 때 브라우저 도구 하나면 몇 초 만에 해결됩니다.

다행히 PDF 합치기·나누기는 **회원가입도, 프로그램 설치도 없이** 브라우저에서 바로 할 수 있습니다. 이 글에서는 합치는 법과 나누는 법을 단계별로 보여 주고, 실제 상황 예시, 무료 도구 고르는 기준, 그리고 **계약서 같은 민감한 PDF를 안전하게 다루는 법**까지 빠짐없이 정리합니다.

## PDF 합치기와 나누기, 언제 쓰나

먼저 어떤 상황에서 무엇이 필요한지 정리했습니다.

| 작업 | 이런 상황 | 결과 |
| --- | --- | --- |
| 합치기 | 영수증·계약서·스캔본을 한 파일로 | 여러 PDF → 1개 |
| 나누기 | 긴 자료에서 일부 페이지만 | 1개 → 필요한 부분만 |
| 순서 바꾸기 | 페이지 순서가 뒤죽박죽 | 원하는 순서로 재배열 |
| 페이지 삭제 | 빈 페이지·불필요한 장 제거 | 깔끔한 PDF |

## PDF 합치기 (단계별)

1. **합칠 PDF 파일들을 준비**합니다.
2. PDF 합치기 도구에 파일을 **순서대로 올립니다.** (한꺼번에 여러 개 선택 가능)
3. 미리보기에서 **원하는 순서로 정렬**합니다. 드래그로 순서를 바꿀 수 있습니다.
4. '합치기'를 누르면 **하나의 파일로 저장**됩니다.

여러 영수증, 계약서, 스캔본을 한 파일로 묶을 때 특히 유용합니다.

### 실제 예시 — 사업자 서류 제출
```text
[전] 따로따로 흩어진 파일
  사업자등록증.pdf   (1쪽)
  통장사본.pdf       (1쪽)
  신분증.pdf         (1쪽)
  → 메일에 3개 첨부, 받는 쪽이 헷갈림 ❌

  ↓ 순서대로 합치기

[후] 거래처제출_서류.pdf  (3쪽 1개 파일)
  → 한 번에 깔끔하게 제출 ✅
```

## PDF 나누기 (단계별)

1. 나눌 PDF를 올립니다.
2. 필요한 **페이지 범위**(예: 3~7페이지)를 지정합니다.
3. '추출'을 누르면 **해당 부분만 새 파일**로 저장됩니다.

### 실제 예시 — 계약서 일부만 공유
```text
[전] 전체계약서.pdf  (전체 42쪽)
  → 상대에게 보여 줄 건 결제 조건(12~14쪽)뿐인데
    42쪽을 통째로 보내면 다른 정보까지 노출 ❌

  ↓ 12~14쪽만 추출

[후] 결제조건_발췌.pdf  (3쪽)
  → 필요한 부분만, 안전하게 공유 ✅
```

## 무료 도구, 안전하게 고르는 법 (가장 중요)

PDF에는 **계약 내용, 신분증, 통장사본, 사업 정보**처럼 매우 민감한 내용이 담기는 경우가 많습니다. 그래서 도구 선택이 이미지보다 더 중요합니다.

| 점검 항목 | 안전한 쪽 | 위험한 쪽 |
| --- | --- | --- |
| 처리 위치 | 내 브라우저 안에서 처리 | 회사 서버로 업로드 |
| 회원가입 | 불필요 | 가입·결제 유도 |
| 파일 보관 | 작업 후 즉시 사라짐 | 서버에 일정 기간 보관 |
| 다운로드 | 결과 바로 내려받기 | 가입·결제 후 다운로드 |

- **브라우저 안에서 처리되는 도구인지:** 파일이 서버로 업로드되지 않고 내 기기에서 처리되면 훨씬 안전합니다. 계약서·신분증이 담긴 PDF는 반드시 이 방식을 쓰세요.
- **작업 후 임시 파일이 남지 않는지:** 서버에 올리는 도구는 일정 시간 파일을 보관하기도 합니다. 민감한 문서라면 피하세요.
- **공용 PC에서는 작업 후 다운로드 폴더 비우기.**

> 한 줄 원칙: **계약서·신분증이 든 PDF는 "내 브라우저 안에서 처리되는 도구"로만.** 서버 업로드형은 피하세요.

## 결론

PDF 합치기·나누기는 **설치·가입 없이, 내 기기 안에서** 1~2분이면 끝나는 작업입니다. 합치기는 '순서대로 올려 정렬', 나누기는 '필요한 페이지 범위 지정'이 전부입니다. 핵심은 **계약서·신분증 같은 민감한 PDF는 브라우저 안에서 처리되는 도구로만** 다루는 것입니다. 간단한 작업일수록, 가볍고 안전한 도구가 제일 빠릅니다.

## 자주 묻는 질문 (FAQ)

**Q. PDF 합치기에 프로그램 설치가 필요한가요?**
아닙니다. 브라우저에서 파일을 올려 순서대로 정렬하고 '합치기'만 누르면 됩니다. 설치도 가입도 필요 없는 도구가 많습니다.

**Q. 합칠 수 있는 파일 개수에 제한이 있나요?**
도구마다 다릅니다. 무료 도구는 한 번에 올리는 개수나 용량에 제한을 두기도 하니, 많을 땐 나눠서 합치세요.

**Q. PDF 순서를 바꿀 수 있나요?**
네. 대부분 미리보기에서 페이지를 드래그해 순서를 바꿀 수 있습니다. 합치기 전에 정렬해 두면 됩니다.

**Q. 긴 PDF에서 몇 페이지만 빼낼 수 있나요?**
나누기(추출) 기능으로 '3~7페이지'처럼 범위를 지정하면 그 부분만 새 파일로 저장됩니다.

**Q. 계약서 같은 민감한 PDF를 올려도 안전한가요?**
서버로 업로드되는 도구라면 주의하세요. 계약서·신분증이 담긴 PDF는 브라우저 안에서만 처리되는 도구를 써야 안전합니다.

**Q. 합친 뒤 화질이나 글자가 깨지지 않나요?**
PDF 합치기는 보통 원본을 그대로 이어 붙여 화질·글자 손상이 없습니다. 단, 무리하게 압축하는 옵션은 글자가 흐려질 수 있으니 확인하세요.

**Q. 무료 도구인데 다운로드하려면 가입하라고 해요.**
그런 곳은 피하세요. 진짜 무료 도구는 결과를 바로 내려받게 해 줍니다. 가입·결제를 막는 도구는 다른 곳을 찾는 게 낫습니다.

**Q. 비밀번호가 걸린 PDF도 합치거나 나눌 수 있나요?**
보통 비밀번호를 먼저 풀어야 작업이 됩니다. 보안이 걸린 문서는 권한이 있는지 확인하고, 신뢰할 수 있는 도구에서만 다루세요.
