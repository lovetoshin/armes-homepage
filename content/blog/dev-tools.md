개발이나 데이터 업무를 하다 보면 "이 변환, 빠르게 할 도구 없나?" 싶은 순간이 잦습니다. JSON을 보기 좋게 정리하거나, 데이터를 인코딩하거나, 색상 코드를 바꾸는 일들입니다. 이런 작업은 프로그램 없이 브라우저에서 바로 처리할 수 있습니다. 이 글에서는 자주 쓰는 개발자용 도구를 모았습니다.

## 데이터 정리·변환

### JSON 포맷(정리)
한 줄로 뭉친 JSON을 보기 좋게 들여쓰기해 줍니다. 구조를 한눈에 파악할 수 있어 개발·디버깅에 필수입니다. 자세한 내용은 [JSON 포맷(정리)하는 법](/blog/json-format)에서 다룹니다.

### 인코딩/디코딩
- **Base64:** 데이터를 문자로 바꿔 전송할 때 씁니다. 원리는 [Base64 인코딩·디코딩 쉽게 이해하기](/blog/base64-guide)에 정리했습니다.
- **URL 인코딩:** 주소에 들어가는 특수문자·한글을 안전하게 바꿉니다. [URL 인코딩이란? 깨진 주소 해결하기](/blog/url-encoder)에서 다룹니다.

## 디자인·실무용

- **색상 코드 변환:** HEX와 RGB를 서로 바꿉니다. 디자인 작업에서 자주 필요합니다.
- **타임스탬프 변환:** 숫자로 된 시간값을 사람이 읽는 날짜로 바꿉니다.
- **해시 생성:** 텍스트의 해시값을 만들어 무결성 확인에 씁니다.

## 텍스트 관련

대소문자 변환, 중복 줄 제거, 글자 수 세기 같은 텍스트 작업은 [텍스트 도구 모음](/blog/text-tools)에 따로 정리했습니다.

## 안전하게 쓰는 법

개발 데이터에는 API 키, 토큰처럼 민감한 정보가 섞일 수 있습니다.

- **민감한 값은 신뢰할 수 있는 도구에서만** 다루세요.
- 가능하면 데이터가 서버로 전송되지 않고 **브라우저 안에서 처리**되는 도구를 쓰세요.
- 회사 정책상 외부 도구 사용이 제한될 수 있으니 확인이 필요합니다.

## 정리

JSON 정리, 인코딩, 색상·시간 변환 같은 개발 작업은 **설치 없이 브라우저에서** 빠르게 처리됩니다. 자주 쓰는 도구를 모아 두면 반복 작업의 시간을 크게 아낄 수 있습니다. 다만 민감한 데이터는 처리 방식을 꼭 확인하고 쓰세요.
