API 응답이나 설정 파일을 열었더니 JSON이 한 줄로 뭉쳐 있어 도무지 알아볼 수 없을 때가 있습니다. JSON 포맷(정리) 도구를 쓰면 이 뭉친 데이터를 보기 좋게 펼쳐 줍니다. 이 글에서는 JSON 정리의 개념과, 자주 만나는 오류를 잡는 요령을 쉽게 정리합니다.

## JSON이란

JSON은 데이터를 주고받을 때 널리 쓰는 형식입니다. 이름과 값이 짝을 이루는 구조라, 사람과 컴퓨터 모두 이해하기 쉽습니다. 다만 전송할 때는 공백 없이 한 줄로 뭉쳐 있는 경우가 많아, 눈으로 읽기 어렵습니다.

## 포맷(정리)이 하는 일

JSON 포맷 도구는 뭉친 데이터를 **줄바꿈과 들여쓰기로 펼쳐** 구조를 한눈에 보이게 합니다.

- 어떤 값이 어디에 속하는지 계층이 보입니다.
- 빠진 괄호, 잘못된 쉼표 같은 **문법 오류를 찾아** 줍니다.
- 반대로 펼쳐진 JSON을 한 줄로 압축(minify)할 수도 있습니다.

## 자주 만나는 오류

JSON은 문법이 엄격해서 작은 실수에도 오류가 납니다.

- **마지막 쉼표:** 항목 끝에 쉼표가 남으면 오류입니다.
- **따옴표 종류:** 이름과 문자열은 큰따옴표(")로 감싸야 합니다. 작은따옴표(')는 안 됩니다.
- **괄호 짝:** 여는 괄호와 닫는 괄호 수가 맞아야 합니다.

포맷 도구는 이런 오류의 위치를 알려 주므로, 어디가 잘못됐는지 빠르게 찾을 수 있습니다.

## 함께 쓰는 도구

JSON 안에 Base64로 인코딩된 값이나 URL이 들어 있는 경우도 많습니다. 그럴 땐 [Base64 인코딩·디코딩 쉽게 이해하기](/blog/base64-guide)와 [URL 인코딩이란? 깨진 주소 해결하기](/blog/url-encoder)를 함께 보면 도움이 됩니다. 그 밖의 개발용 도구는 [개발자용 온라인 도구 모음](/blog/dev-tools)에 정리했습니다.

## 안전하게 쓰기

JSON에는 API 키, 개인정보 같은 민감한 값이 담길 수 있습니다. 이런 데이터는 **브라우저 안에서 처리되는 도구**에서 다루는 게 안전합니다. 외부 서버로 전송되는지 확인하세요.

## 정리

JSON 포맷은 뭉친 데이터를 **보기 좋게 펼치고 오류를 찾아** 주는 작업입니다. 마지막 쉼표, 따옴표 종류, 괄호 짝만 신경 쓰면 대부분의 오류가 해결됩니다. 민감한 값이 담긴 JSON은 처리 방식을 확인하고 쓰세요.
