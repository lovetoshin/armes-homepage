보고서를 쓰다 글자 수가 궁금하고, 이메일 명단에서 중복을 지워야 하고, 영문 대소문자를 한 번에 바꿔야 할 때가 있습니다. 이런 **자잘하지만 손이 많이 가는 텍스트 작업**을, 많은 분이 메모장이나 엑셀로 끙끙대며 합니다. 사실은 브라우저에서 **클릭 한 번**이면 끝나는 일인데 말입니다.

텍스트 도구는 종류가 많아 보이지만, 자주 쓰는 건 몇 개로 정해져 있습니다 — **글자 수 세기, 대소문자 변환, 중복 줄 제거·정렬, 찾기·바꾸기.** 이 글에서는 각 도구가 어떤 상황에 쓰이고, 실제로 어떻게 동작하는지(전/후 예시), 그리고 안전하게 쓰는 법까지 정리합니다.

## 자주 쓰는 텍스트 도구 한눈에

| 도구 | 이런 상황 | 효과 |
| --- | --- | --- |
| 글자 수 세기 | 자소서·보고서 글자 제한 | 공백 포함/미포함 정확히 |
| 대소문자 변환 | 영문 통일 필요 | 한 번에 변환 |
| 중복 줄 제거 | 명단·키워드 정리 | 중복 자동 삭제 |
| 정렬 | 가나다·ABC순 필요 | 자동 정렬 |
| 찾기·바꾸기 | 긴 글 단어 일괄 교체 | 메모장보다 빠름 |
| 공백·줄바꿈 정리 | 복붙 후 지저분한 텍스트 | 깔끔하게 |

## 글자 수·단어 수 세기

자기소개서, 보고서, 게시글에 글자 수 제한이 있을 때 가장 많이 씁니다. **공백 포함·미포함**을 따로 세어 주는 도구를 쓰면 정확합니다.

> 주의: 한글은 제출처마다 기준이 다릅니다. "공백 포함 1000자 이내"인지 "공백 제외"인지 꼭 확인하세요. 같은 글도 공백 포함/미포함이 수십 자 차이 납니다.

## 대소문자·전각/반각 변환

```text
입력 :  armes tools
대문자 :  ARMES TOOLS
소문자 :  armes tools
첫글자 :  Armes Tools
```

- **대소문자 변환:** 영문을 전부 대/소문자로, 또는 첫 글자만 대문자로.
- **전각 → 반각:** 데이터에 섞인 전각 문자(`ＡＢＣ１２３`)를 일반 문자(`ABC123`)로 정리. 엑셀·데이터 작업에서 자주 필요합니다.

## 중복 줄 제거·정렬 (실전 예시)

명단·목록에서 **중복된 줄을 한 번에 제거**하고 가나다·ABC순으로 정렬합니다. 이메일·키워드 목록 정리에 특히 유용합니다.

```text
[전]              [중복 제거 + 정렬 후]
kim@a.com         choi@c.com
lee@b.com    →    kim@a.com
kim@a.com         lee@b.com
choi@c.com
```

이메일 1,000개 명단에서 중복을 손으로 찾는 건 불가능하지만, 도구로는 1초입니다.

## 찾기·바꾸기 / 공백 정리

긴 글에서 특정 단어를 한꺼번에 바꿀 때 메모장보다 편리합니다. 웹·문서에서 복사한 텍스트에 **줄바꿈·이중 공백이 지저분하게** 섞였을 때도, 한 번에 정리할 수 있습니다.

## ⚠️ 안전하게 쓰는 법

텍스트에는 **회사 기밀·고객 명단·개인정보**가 담기는 경우가 많습니다.

- 민감한 내용은 **데이터가 서버로 전송되지 않고 브라우저 안에서 처리되는** 도구에서만 다루세요.
- 공용 PC에서는 작업 후 입력 내용을 지우세요.
- 고객 이메일·전화번호 명단은 특히 신중하게 다뤄야 합니다.

## 결론

글자 수 세기, 대소문자 변환, 중복 제거 같은 텍스트 작업은 **설치 없이 브라우저에서** 해결됩니다. 자주 쓰는 도구를 즐겨찾기에 모아 두면, 같은 작업에 들이던 시간을 크게 아낄 수 있습니다. 핵심은 "이 작업, 분명 도구가 있을 거야"라고 떠올리는 습관입니다.

## 자주 묻는 질문 (FAQ)

**Q. 글자 수는 공백을 포함해서 세나요?**
도구는 보통 공백 포함·미포함을 모두 보여 줍니다. 제출처 기준(포함/제외)을 확인하고 맞는 숫자를 쓰세요.

**Q. 한글 글자 수도 정확히 세지나요?**
네. 한글·영문·숫자·공백을 구분해 세어 줍니다. 다만 기관마다 기준이 달라 제출 기준을 꼭 확인하세요.

**Q. 이메일 명단에서 중복을 어떻게 한 번에 지우나요?**
중복 줄 제거 도구에 목록을 붙여넣으면 똑같은 줄을 자동으로 삭제합니다. 정렬까지 하면 더 깔끔합니다.

**Q. 전각 문자가 뭔가요? 왜 정리해야 하나요?**
`ＡＢＣ`처럼 폭이 넓은 문자입니다. 데이터에 섞이면 검색·집계가 어긋나므로 일반(반각) 문자로 통일하는 게 좋습니다.

**Q. 메모장 찾기·바꾸기와 뭐가 다른가요?**
여러 단어를 한 번에 바꾸거나, 줄바꿈·공백 정리, 정규식 같은 고급 기능을 지원하는 경우가 많아 더 빠릅니다.

**Q. 복사한 글의 줄바꿈이 엉망인데 정리되나요?**
됩니다. 불필요한 줄바꿈·이중 공백을 한 번에 정리하는 기능이 있어, 복붙 후 정돈에 유용합니다.

**Q. 고객 명단을 온라인 텍스트 도구에 넣어도 되나요?**
서버로 전송되는 도구라면 위험합니다. 개인정보가 담긴 명단은 브라우저 안에서만 처리되는 도구를 쓰세요.

**Q. 자주 쓰는 도구를 매번 검색하기 번거로워요.**
즐겨찾기에 모아 두거나, 여러 도구를 한곳에 묶어 둔 도구 모음을 쓰면 편합니다.
