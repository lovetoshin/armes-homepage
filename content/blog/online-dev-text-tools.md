업무나 공부를 하다 보면 "이 작업, 분명 도구가 있을 텐데" 싶은 순간이 많습니다. 글자 수를 세거나, 이메일 명단에서 중복을 지우거나, 한 줄로 뭉친 데이터를 보기 좋게 정리하는 일들 말입니다. 많은 분이 이런 자잘한 작업을 메모장이나 엑셀로 끙끙대며 합니다. 사실은 **브라우저에서 클릭 한 번**이면 끝나는 일인데 말이죠.

이런 도구는 종류가 많아 보이지만, 자주 쓰는 건 손에 꼽습니다. 한 번 알아 두면 같은 작업에 들이던 시간을 매번 아낄 수 있습니다. 이 글에서는 텍스트·개발 실무에서 자주 쓰는 온라인 도구를 **용도별로 한곳에** 모으고, 각 도구가 실제로 어떤 일을 하는지(전/후 예시 포함), 그리고 민감한 데이터를 안전하게 다루는 법까지 정리합니다.

## 텍스트 관련 도구

### 글자 수 세기
보고서, 자기소개서, 게시글에 글자 수 제한이 있을 때 가장 많이 씁니다. **공백 포함·미포함**을 따로 세어 주는 도구를 쓰면 정확합니다.

> 주의: 제출처마다 "공백 포함 1,000자"인지 "공백 제외"인지 기준이 다릅니다. 같은 글도 수십 자 차이가 나니 꼭 확인하세요.

### 대소문자·전각/반각 변환
영문을 한 번에 대/소문자로 바꾸거나, 데이터에 섞인 전각 문자(`ＡＢＣ`)를 일반 문자(`ABC`)로 정리할 때 씁니다.

```text
입력 :  armes tools
대문자 :  ARMES TOOLS
첫글자 :  Armes Tools
```

### 중복 줄 제거·정렬
명단이나 목록에서 중복을 없애고 가나다·ABC순으로 정렬합니다. 이메일·키워드 정리에 특히 강합니다.

```text
[전]              [중복 제거 + 정렬 후]
kim@a.com         choi@c.com
lee@b.com    →    kim@a.com
kim@a.com         lee@b.com
choi@c.com
```

이메일 1,000개에서 중복을 손으로 찾는 건 불가능하지만, 도구로는 1초입니다.

## 개발자·실무용 도구

### JSON 정리(포맷팅)
한 줄로 뭉친 데이터를 보기 좋게 펼쳐 줍니다. API 응답을 읽거나 오류 위치를 찾을 때 필수입니다.

```text
[전] {"id":1,"tags":["a","b"]}
[후] {
       "id": 1,
       "tags": ["a", "b"]
     }
```

### 인코딩/디코딩
- **Base64:** 데이터를 글자로 바꿔 전송할 때 씁니다(`ARMES` → `QVJNRVM=`).
- **URL 인코딩:** 주소에 들어가는 특수문자·한글을 안전하게 바꿉니다(`공백` → `%20`).

### 색상 코드·타임스탬프 변환
- **색상 코드 변환:** 디자인은 HEX(`#1D62F0`), 코드는 RGB(`rgb(29,98,240)`)가 편할 때가 있어 서로 바꿉니다.
- **타임스탬프 변환:** 로그·DB에 숫자로 저장된 시간(`1750000000`)을 사람이 읽는 날짜로 바꿉니다.

## 도구를 쓸 때의 원칙 (안전)

편하다고 아무 도구에나 데이터를 넣으면 안 됩니다. 텍스트·개발 데이터에는 **회사 기밀, 고객 명단, API 키, 개인정보**가 섞이기 쉽습니다.

- **내 기기에서 처리되는지 확인:** 데이터가 서버로 전송되지 않고 브라우저 안에서 처리되면 더 안전합니다.
- **민감한 값은 더미로:** 운영 API 키·토큰은 절대 아무 온라인 도구에 붙여넣지 마세요. 테스트용 가짜 값으로 바꿔 다루세요.
- **공용 PC는 작업 후 비우기:** 입력 내용을 지우고 다운로드 폴더도 정리하세요.

## 이미지·PDF까지 더하면

이미지나 PDF 작업까지 더하면 웬만한 일은 브라우저 하나로 끝납니다. 이미지 변환은 [설치 없이 쓰는 무료 이미지 변환 도구](/blog/free-image-converter)에, PDF 작업은 [가입 없이 PDF 합치기·나누기 하는 법](/blog/pdf-merge-split-free)에, 텍스트 도구 상세는 [텍스트 도구 모음](/blog/text-tools)과 [개발자용 온라인 도구 모음](/blog/dev-tools)에 정리해 두었습니다.

이런 도구를 한곳에 모아 가입·설치 없이 쓰도록, 아르메스도 [ARMES Tools](/projects/tools)를 준비하고 있습니다.

## 결론

자주 쓰는 텍스트·개발 작업은 대부분 **설치 없이 브라우저에서** 해결됩니다. 글자 수 세기, 중복 제거, JSON 정리 같은 도구를 즐겨찾기에 모아 두면, 매번 같은 작업에 들이던 시간을 아낄 수 있습니다. 핵심은 "이 작업, 도구가 있을 거야"라고 한 번 떠올리는 습관, 그리고 **민감한 데이터는 처리 방식을 확인하고 쓰는** 신중함입니다.

## 자주 묻는 질문 (FAQ)

**Q. 온라인 도구는 설치가 필요 없나요?**
대부분 브라우저에서 바로 씁니다. 글자 수 세기·JSON 정리·인코딩 등은 페이지를 열어 입력만 하면 됩니다.

**Q. 어떤 도구부터 알아 두면 좋나요?**
가장 자주 쓰이는 건 글자 수 세기, 중복 줄 제거, JSON 정리, URL 인코딩입니다. 이 넷만 익혀도 체감 효과가 큽니다.

**Q. 운영 API 키를 온라인 도구에 넣어도 되나요?**
위험합니다. 입력값이 서버로 전송되는 도구라면 키가 유출될 수 있습니다. 민감 값은 더미로 바꿔 다루세요.

**Q. JSON 정리는 왜 필요한가요?**
API 응답이 한 줄로 뭉쳐 오면 읽기 어렵습니다. 정리하면 구조가 보이고 문법 오류 위치까지 짚어 줘 작업이 빨라집니다.

**Q. Base64와 URL 인코딩은 무엇이 다른가요?**
Base64는 데이터를 글자로 포장하는 것, URL 인코딩은 주소에 못 쓰는 문자를 `%` 형태로 바꾸는 것입니다. 목적이 다릅니다.

**Q. 이메일 명단 중복을 한 번에 지울 수 있나요?**
중복 줄 제거 도구에 목록을 붙여넣으면 똑같은 줄을 자동으로 삭제합니다. 정렬까지 하면 더 깔끔합니다.

**Q. 글자 수는 공백을 포함해서 세나요?**
도구는 보통 공백 포함·미포함을 모두 보여 줍니다. 제출처 기준을 확인하고 맞는 숫자를 쓰세요.

**Q. 여러 도구를 매번 찾기 번거로워요.**
자주 쓰는 도구를 즐겨찾기에 모아 두거나, 여러 도구를 한곳에 묶어 둔 도구 모음을 쓰면 편합니다.
