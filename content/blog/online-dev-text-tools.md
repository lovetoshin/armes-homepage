업무나 공부를 하다 보면 "이 작업, 분명 도구가 있을 텐데" 싶은 순간이 많습니다. 글자 수를 세거나, 대소문자를 바꾸거나, 코드 형식을 정리하는 일들 말입니다. 이런 자잘한 작업은 프로그램을 깔지 않아도 브라우저에서 바로 할 수 있습니다. 이 글에서는 자주 쓰는 온라인 텍스트·개발자 도구를 용도별로 모았습니다.

## 텍스트 관련 도구

### 글자 수 세기
보고서, 자기소개서, 게시글에 글자 수 제한이 있을 때 유용합니다. 공백 포함·미포함을 따로 세어 주는 도구가 많습니다.

### 대소문자·전각/반각 변환
영문 대소문자를 한 번에 바꾸거나, 전각 문자를 반각으로 정리할 때 씁니다. 데이터를 다룰 때 자주 필요합니다.

### 중복 줄 제거·정렬
명단이나 목록에서 중복을 없애고 가나다순으로 정렬하는 작업도 도구 하나면 끝납니다.

### 찾기·바꾸기
긴 글에서 특정 단어를 한 번에 바꿀 때, 메모장보다 편리한 온라인 도구가 있습니다.

## 개발자·실무용 도구

### JSON 정리(포맷팅)
줄바꿈 없이 한 줄로 뭉친 JSON 데이터를 보기 좋게 정리해 줍니다. 개발·데이터 업무에서 필수입니다.

### 인코딩/디코딩
URL 인코딩, Base64 변환처럼 데이터를 다룰 때 자주 쓰는 변환을 바로 처리합니다.

### 색상 코드 변환
디자인 작업에서 HEX·RGB 색상 코드를 서로 바꿀 때 편리합니다.

### 타임스탬프 변환
숫자로 된 시간값을 사람이 읽는 날짜로 바꿀 때 씁니다.

## 도구를 쓸 때의 원칙

- **민감한 데이터 주의:** 회사 기밀이나 개인정보가 담긴 텍스트는 신뢰할 수 있는 도구에서만 다루세요.
- **내 기기에서 처리되는지 확인:** 데이터가 서버로 전송되지 않고 브라우저 안에서 처리되면 더 안전합니다.

이미지나 PDF 작업까지 더하면 웬만한 작업은 브라우저 하나로 끝납니다. 이미지 변환은 [설치 없이 쓰는 무료 이미지 변환 도구](/blog/free-image-converter)에, PDF 작업은 [가입 없이 PDF 합치기·나누기 하는 법](/blog/pdf-merge-split-free)에 정리해 두었습니다.

## 정리

자주 쓰는 텍스트·개발자 작업은 대부분 **설치 없이 브라우저에서** 해결됩니다. 글자 수 세기, 중복 제거, JSON 정리 같은 도구를 즐겨찾기에 모아 두면, 매번 같은 작업에 들이던 시간을 아낄 수 있습니다. 핵심은 "이 작업, 도구가 있을 거야"라고 한 번 떠올리는 습관입니다.
