## 왜 바꿨나
애드센스가 armes.co.kr을 **"가치 없는 콘텐츠"로 반려**했습니다. 애드센스는 **도메인 단위 심사**라 루트 홈(armes.co.kr)이 대표 평가 대상인데, 기존 홈이 **배너 위주라 읽을 글이 거의 없고 블로그 200편이 푸터에만 숨어** 있었습니다. 그래서 홈에 **실질 텍스트 + 블로그 노출**을 추가했습니다.

## ⚠️ 블로그 세션이 꼭 알아야 할 것

### 1. 블로그 글을 쓰면 홈에도 자동 노출됩니다 (좋은 것)
`LatestBlog.tsx`가 `lib/posts.ts`의 **`getAllPosts("blog", "ko")`** 결과에서 **최신 9편(날짜 내림차순)**을 홈에 자동으로 띄웁니다. 새 블로그 글을 쓰면 홈 상단 블로그 섹션에 바로 반영됩니다. 따로 손댈 것 없습니다.

### 2. 이 필드들을 바꾸면 홈이 깨집니다
`LatestBlog.tsx`가 각 글에서 아래 필드를 그대로 씁니다. **필드명·`getAllPosts` 시그니처를 바꾸지 마세요:**
- `post.slug` (링크 `/blog/${slug}`)
- `post.title`
- `post.excerpt` (요약 2줄)
- `post.thumbnail` (커버 이미지, 보통 `/blog/covers/*.png`. **없으면 📝 이모지로 폴백** 처리돼 있으니 커버 없어도 안 깨짐)
- `post.category` (있으면 배지로 표시, 없으면 배지 생략)
- `post.date`

→ 블로그 글 프론트매터에 `thumbnail`(또는 `image`), `excerpt`, `category`를 채워두면 홈 카드가 더 예쁘게 나옵니다.

### 3. app/page.tsx를 수정할 때 (충돌 주의)
블로그 관련해서 `app/page.tsx`를 손대실 경우, 제가 넣은 아래 **import 2줄 + JSX 2줄을 지우지 마세요**:
```tsx
import CompanyIntro from "@/components/sections/CompanyIntro";
import LatestBlog from "@/components/sections/LatestBlog";
// ...
<CompanyIntro />   // TechnologySection 다음
<LatestBlog />     // ProjectsSection 다음
```
이 두 줄이 빠지면 애드센스 대응이 무효가 됩니다.
