## 0. 한 줄 결론

**ARMES SEO는 구축(공사) 단계를 종료하고 관찰 단계로 전환한다. 아래 5개 트리거 중 하나가 오기 전까지 SEO 구조·콘텐츠를 추가로 건드리지 않는다.**

## 1. 무엇이 끝났나 (완료 산출물 체크)

| 영역 | 상태 | 내용 |
| --- | --- | --- |
| 기술 SEO | ✅ 완료 | robots.txt, sitemap.xml(75개 URL), canonical, 메타(제목·설명) |
| 구조화 데이터 | ✅ 완료 | BlogPosting / SoftwareApplication / BreadcrumbList(JSON-LD) |
| 서비스 페이지 | ✅ 완료 | 8개 서비스 상세(`/projects/*`) + 상태 체계(운영중/배포대기중/준비중/연구중) |
| 블로그 | ✅ 완료 | 48편 전부 장문화 + 발행일 60일 재분배 + 정렬 버그 수정 |
| 뉴스 구조 | ✅ 완료 | News 목록·상세·정렬·frontmatter 템플릿 |
| 앱 개인정보처리방침 | ✅ 완료 | RewardTalk / TravelMoa / CocoPing 3종 (`/(서비스)/privacy`) + 상세페이지 연결 |
| 검색엔진 등록 | ✅ 완료 | 아래 2장 참조 |

## 2. 검색엔진 등록 현황 (2026-06-25 기준, 형님 직접 확인)

### 구글 (Google Search Console)
- ✅ 사이트 등록 완료
- ✅ sitemap 제출 완료

### 네이버 (Search Advisor 웹마스터 도구)
- ✅ 사이트 등록 완료
- ✅ 소유확인 완료
- ✅ `sitemap.xml` 등록 완료
- ✅ `sellerai/sitemap.xml` 등록 완료
- ✅ 주요 URL 수집 요청 완료 (수집요청 목록: `네이버-수집요청/네이버_수집요청_URL목록.xlsx`)

> 사이트 측 단서 실측: robots.txt 정상(네이버봇 Yeti 허용), 네이버 소유확인 메타태그 삽입 확인, sitemap 75개 URL 정상.

## 3. 종료 선언 — 관찰 단계로 전환

지금부터 **유지보수 모드**입니다. "씨는 다 뿌렸고, 싹이 나는지 지켜보는" 단계입니다.

### 하지 않는 것 (트리거 전까지 동결)
- 🚫 SEO 구조 변경 (sitemap 재설계, canonical/도메인 통일, JSON-LD 개편)
- 🚫 블로그 대량 생산
- 🚫 기존 글 재작업
- 🚫 GSC 데이터 없이 SEO 공사
- 🚫 www/non-www 도메인 손대기
- ✅ 예외: **명백한 버그(오타·깨진 링크·사실 오류)만** 그때그때 수정

### 다시 움직이는 트리거 (이 중 하나가 오면 해당 작업만)
1. **GSC 데이터가 의미 있게 쌓이는 시점**(약 1개월) → 효자/문제 글 핀셋 보수
2. **RewardTalk 운영중 전환** → 상태 변경 체크리스트 가동 + 출시 News
3. **TravelMoa 운영중 전환** → 동일
4. **CocoPing 운영중 전환** → 동일
5. **SellerAI 또는 ARMES Tools 대형 기능 추가** → 기능 갱신 + News

> 트리거 발생 시 실제 작업 절차 → [운영-가이드.md] 7장 "서비스 상태 변경 체크리스트"

## 4. News 작성 기준 (관찰 단계에도 계속 누적)

블로그는 멈추지만 **News는 실제 사건이 생기면 작성**합니다. (회사가 살아있다는 신호)

- 작성하는 사건: **출시 · 스토어 등록 · 기능 추가 · 개발 마일스톤 · 제휴**
- 원칙: **일어난 일만 / 과장 금지 / 미래 약속 금지**
- 종류: 마일스톤 News(큰 사건) + 개발 노트(진행 상황, 월 1~2편) → 상세 [운영-가이드.md] 3장

## 5. 향후 관찰 체크리스트 (구글 + 네이버)

새로 글 쓰는 게 아니라 **"지켜보기"**가 일입니다. 숫자 하나에 일희일비 금지 — 큰 흐름만 봅니다.

### 🔵 구글 GSC
| 시점 | 보는 것 | 판단 |
| --- | --- | --- |
| 1주(~7/2) | 색인 시작·sitemap 처리·치명 오류 0 | 읽기 시작했나 |
| 2주(~7/9) | 첫 노출·어떤 검색어로 보이나 | 노출 생겼나 |
| 1개월(~7/25) | 클릭·CTR·게재순위·유입 키워드 TOP | **다음 액션 결정**(효자글 보강) |
| 3개월 | 추세 우상향·카테고리별 성과 | 구조 유지 + 선택 강화 |

### 🟢 네이버 Search Advisor
| 시점 | 보는 것(메뉴) | 판단 |
| --- | --- | --- |
| 1~2주 | 요약 > 수집 현황 / 웹페이지 수집 반영 여부 | 수집 요청 URL이 색인되나 |
| 1개월 | 리포트 > 검색 유입·검색어 | 어떤 생활정보 글이 먹히나 (코스트코·주유·여행 주목) |
| 상시 | 리포트 > 사이트 최적화 경고 | 경고 뜨면 그것만 점검 |

> 네이버는 구글보다 **수집이 느립니다.** 반영 안 됐다고 조급해하지 말 것. 생활정보 블로그가 네이버 유입의 핵심.
