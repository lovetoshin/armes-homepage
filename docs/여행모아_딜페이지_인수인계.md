# 여행모아 딜 웹 페이지 — 마케팅 인수인계

작성: 여행모아 담당 / 2026-07-27
목적: 블로그부스터가 블로그 글 하단에 붙이는 "여행모아 특가" 링크를, 실제로 열리는 **웹 딜 상세 페이지**에 착지시킨다.

---

## 1. 무엇을 만들었나 (여행모아 쪽에서 완료)

아르메스 본체(armes-homepage) 안에 **여행모아 딜 상세 웹 페이지**를 새로 만들었습니다.

- **주소 규칙: `https://www.armes.co.kr/travelmoa/deal/{딜id}`**
- `{딜id}` = 여행모아 수파베이스 `travel_deals` 테이블의 `id` (블로그부스터가 지금 읽고 있는 그 id 그대로).
- 화면에 뜨는 것: 여행사·대표사진·제목·국내/해외·패키지/항공 배지·기간·출발귀국일·출발지·여행지·**정가(취소선)·할인율·특가**·[여행사에서 예약하기] 버튼(→ 실제 `deal_url`)·여행모아 앱 다운로드 유도.
- **판매 종료·삭제된 딜**(오래된 블로그 링크)은 404가 아니라 "마감된 특가예요" 안내 화면 + 앱 유도로 부드럽게 처리됩니다.
- 카톡·블로그 공유 시 **미리보기(제목·사진·특가)**가 뜨도록 메타태그(OpenGraph)까지 넣었습니다.

---

## 2. 블로그부스터가 할 일 (딱 하나)

블로그 링크를 `deal_url`(여행사 직접 주소) 대신 **이 웹 페이지 주소로 바꾸면 끝**입니다.

- `TRAVELMOA_WEB_BASE = https://www.armes.co.kr`
- 링크 조합: **`${TRAVELMOA_WEB_BASE}/travelmoa/deal/${deal.id}`**

즉 이미 갖고 있는 딜 `id`만 뒤에 붙이면 됩니다. (딜 데이터를 새로 조회할 필요 없음 — id만 있으면 됨.)

> 참고: 지금처럼 `deal_url`로 바로 걸어도 동작은 하지만, 웹 딜 페이지를 거치면 ①앱 없는 사람도 특가를 보고 ②나중에 앱 자동 열기(아래 4번)로 확장할 수 있어 권장합니다.

---

## 3. 배포 전 확인할 것 (아르메스 쪽 · 형님/마케팅)

이 페이지는 여행모아 수파베이스를 **공개 읽기(anon)**로 읽습니다. armes-homepage **Vercel 프로젝트 환경변수**에 아래 2개가 등록돼야 실서버에서 작동합니다.

| Key | Value |
|-----|-------|
| `TRAVELMOA_SUPABASE_URL` | 여행모아 수파베이스 주소 |
| `TRAVELMOA_SUPABASE_ANON_KEY` | 여행모아 공개 읽기(anon) 키 |

- **로컬 `.env`에는 등록 완료**(`f:\APP\armes\.env`).
- **Vercel(실서버)에도 위 2개를 넣어야 함** (Production and Preview). ← 등록 후 재배포되면 실제로 열립니다.
- ⚠️ `service_role`(전권) 키는 **웹에 넣지 말 것**. 딜 페이지는 읽기 전용이라 anon이면 충분합니다.
- 아르메스 본체 수파베이스와는 **이름표(`TRAVELMOA_`)로 완전히 분리**되어 절대 안 섞입니다.

---

## 4. 다음 단계 (페이즈2-B · 앱 자동 열기 · 다음 앱 빌드에 묶기)

지금은 링크를 누르면 **웹 페이지**가 열립니다(앱 유무 무관, 100% 동작).
"폰에 여행모아 앱이 있으면 앱이 열리게" 하려면 **App Links**가 필요하며, 이건 **여행모아 앱 새 빌드 + 플레이스토어 재배포**가 있어야 합니다(OTA 불가). 단독 빌드는 아까우니 **다음 여행모아 앱 빌드 때 다른 수정과 묶어서** 진행 예정.

필요 작업(앱 빌드 시):
- 앱 `app.json`에 App Links 설정(intentFilters autoVerify / iOS associatedDomains)
- `https://www.armes.co.kr/.well-known/assetlinks.json` 호스팅 — **Play 앱 서명 키의 SHA256** 지문 필요(업로드 키 아님, Play Console > 앱 무결성 > 앱 서명에서 확인)
- 네이티브 리빌드 → versionCode 올려 재배포

## 5. 파일 위치 (여행모아 담당이 만든 것)

- `f:\APP\armes\lib\travelmoa.ts` — 딜 조회 함수 + 표시 도우미 (여행모아 수파베이스 REST 호출)

- `f:\APP\armes\.env` — `TRAVELMOA_` 환경변수 (로컬)
